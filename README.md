# 🎬 MyFilmes

O **MyFilmes** é uma aplicação desenvolvida em .NET para gestão e consulta do catálogo de filmes. O projeto permite organizar títulos e realizar pesquisas, como a filtragem de filmes por género.

---

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** C#
- **Framework:** .NET
- **Estrutura:** Solução em Visual Studio (`MyFilmes.slnx`)

---

## 🚀 Funcionalidades

- [x] Cadastro de catálogo de filmes (CRUD)
- [x] Pesquisa e filtragem de filmes por género
- [ ] Favoritar filmes
- [ ] Marcar filme como assistido.
- [ ] Atribuição de nota a um filme
- [ ] Relatórios

---
